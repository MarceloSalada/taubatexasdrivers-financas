# TaubatexasDrivers - Finanças

App web mobile-first para controle financeiro de motoristas.

## Como rodar localmente
```bash
npm install
npm run dev
```

## Como publicar na Vercel
1. Crie um repositório no GitHub
2. Suba todos os arquivos deste projeto
3. Entre em https://vercel.com
4. Faça login com GitHub
5. Clique em **New Project**
6. Escolha o repositório
7. Clique em **Deploy**

## Tecnologias
- React
- Vite
- Recharts
- Lucide React
- localStorage
